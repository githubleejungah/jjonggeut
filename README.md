# 쫑긋 — 듣고, 모으고, 따라 말하고, 다시 떠올리는 영어 습관

하루 30~60분을 내는 한국어 화자 성인(A2~B1)을 위한 영어 학습 웹앱 시범판이다.
짧은 자연 대화를 듣고, 쓸 만한 표현(청크)을 모으고, 따라 말하고, 간격을 두고 다시 떠올리게 한다.
하루 목표를 이루면 귀가 작은 통통한 토끼가 축하해 주고 조금씩 자란다.

<img src="site/img/rabbit.svg" alt="쫑긋 토끼" width="96">

## 지금 상태

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 뼈대 | 학습 규칙·음성 엔진·처음 시작 화면(토끼 이야기·관심사·색 테마)·점검 도구 | 완료 |
| 2 콘텐츠 | 콘텐츠·문장·라이선스 데이터, VOA 3편(199문장, 시각·번역) | 완료 |
| 3 루프 | 문장 플레이어, 자동 멈춤, 녹음 비교, 요지 적기 | 예정 |
| 4 카드·복습 | 청크 카드, 확신도+채점, 새 카드 30% 섞기 | 예정 |
| 5 진단·어휘 | 간이 수준 진단(CEFR), A1~B1 어휘 팩 | 예정 |
| 6 기록·토끼 | 달력·그래프, 토끼 성장 5단계, 휴대폰 시험, 배포 | 예정 |

## 학습 원리 (근거가 있는 것만)

| 원리 | 앱에서 |
|---|---|
| 간격 반복 | 복습 간격 1·3·7·14·30·60일, 장기 기억은 120일마다 확인 |
| 인출 연습 | 정답을 보기 전에 먼저 떠올린다. "다시 읽기" 모드는 두지 않는다 |
| 이해 가능한 입력 | 아는 단어가 95~98%인 콘텐츠를 고른다 (CEFR 등급 어휘 기준) |
| 출력 | 따라 말하기(섀도잉)와 다시 말하기를 녹음한다 |
| 착각 바로잡기 | 확신하고 틀린 답("착각")을 따로 잡아 먼저 복습한다 |

## 실행

```bash
python -m http.server 8010 --directory site
```

브라우저에서 `http://127.0.0.1:8010`을 연다. 서버도 빌드 도구도 필요 없다.

## 점검

```bash
python pipeline/check.py
```

시험(학습 규칙·음성), 자바스크립트 문법, 오래된 아이폰이 모르는 정규식, 화면 문구, 캐시 번호, 이모지, 비밀 값을 확인한다.
`main`에 올리면 GitHub Actions가 같은 점검을 하고, 통과하면 `site/`만 GitHub Pages로 배포한다.

## 구조

```text
site/                 정적 웹앱 (이 폴더만 배포)
  index.html
  js/review.js        학습 규칙: 라이트너 상자, 오늘 할 카드, 일지, 백업 (화면 없음)
  js/speech.js        음성 엔진: 문장 단위 읽기, 휴대폰 고장 대비 4가지
  js/app.js           화면
  css/style.css       디자인 규칙과 색
  i18n/ko.json        화면 문구
  img/rabbit.svg      토끼 시안
  data/contents.json  콘텐츠·문장·라이선스 (데이터 파일 하나 = 계약)
  audio/              VOA 음성 (공공 저작물)
tests/                시험 (node --test, python -m unittest)
pipeline/check.py     종합 점검
pipeline/validate.py  콘텐츠 검사: 라이선스 없거나 만료되면 게시 차단, 문장 시각
pipeline/voa_text.py  VOA 페이지에서 본문만 뽑기
pipeline/align.py     문장 시각 맞추기 (faster-whisper 단어 시각 → 원문 문장)
pipeline/import_content.py  미리보기 → 승인 → 적용
docs/                 결정 요약, 데이터 모양
```

## 기록과 개인정보

- 기록은 사용자 기기의 브라우저에만 저장한다(서버 없음). 정보 화면에서 파일로 내보내고 가져올 수 있다.
- 녹음은 기기 밖으로 보내지 않는다.

## 콘텐츠 출처

듣기 콘텐츠는 [VOA Learning English](https://learningenglish.voanews.com/p/6861.html)의 공공 저작물(음성과 글)이다. 원문 페이지의 통신사(AP·로이터·AFP) 사진은 쓰지 않는다. 한국어 번역은 Claude 초안을 사람이 승인했다.

## 다시 쓴 코드

학습 규칙(`review.js`), 음성 엔진, 화면 도구, 점검·배포 흐름은 같은 사람이 만든 [필드워드](https://github.com/githubleejungah/field-words)에서 가져와 쫑긋에 맞게 바꿨다. 바꾼 점은 각 파일 맨 위에 적었다.
