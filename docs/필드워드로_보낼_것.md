# 필드워드로 보낼 것 (역반영 목록)

- 만든 날: 2026-11-12
- 읽는 곳: 필드워드 주간 자동 작업의 ⑤단계(`field-words/docs/운영_자동화.md`)가 이 파일을 읽고 `pipeline/reports/역반영제안_날짜.md`를 쓴다.
- 규칙: **자동 작업은 제안까지만 한다.** 필드워드 코드는 사람이 "고쳐 줘"라고 승인한 뒤에만 바뀐다(필드워드 ADR-0004와 같다).
- 쓰는 법: 쫑긋에서 필드워드에도 쓸 만한 개선이 생기면 아래 표에 한 줄 추가한다. 필드워드에 반영되면 상태를 `반영함 (날짜, 커밋)`으로, 맞지 않으면 `보류 (이유)`로 바꾼다.
- 반대 방향(필드워드 → 쫑긋)은 `field-words/docs/재사용_가이드.md`의 6번 '바뀐 내용'을 읽고 반영한다.
