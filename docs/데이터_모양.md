# 데이터 모양 — 콘텐츠·문장·라이선스

- 만든 날: 2026-11-12 (2단계)
- 파일: `site/data/contents.json` 하나. 관리 도구와 화면은 이 파일로만 이어진다 (필드워드의 "데이터 파일 하나 = 계약").
- 검사: `python pipeline/validate.py` (종합 점검 `check.py`가 함께 돌린다). 통과하지 못하면 배포하지 않는다.

## 가장 중요한 규칙

**라이선스가 없거나 만료된 콘텐츠는 게시하지 않는다.** 검사가 막는다 (기능요구서 F-03, F-17).

## 전체 모양

```json
{
  "format": 1,
  "licenses": [ { "id": "voa-public-domain", "...": "..." } ],
  "series": [ { "id": "lle2", "...": "..." } ],
  "contents": [ { "id": "voa-travel-001", "...": "..." } ]
}
```

## License (라이선스)

| 칸 | 필수 | 뜻 |
|---|---|---|
| `id` | 예 | 영문 소문자·숫자·하이픈 |
| `name` | 예 | 사람이 읽는 이름. 예: "VOA Learning English 공공 저작물" |
| `kind` | 예 | `public_domain` / `cc_by` / `cc_by_sa` / `contract` / `own` |
| `holder` | 예 | 권리자. 예: "Voice of America (U.S. Agency for Global Media)" |
| `terms_url` | 예 | 이용 조건을 확인한 페이지 |
| `checked_at` | 예 | 이용 조건을 마지막으로 확인한 날 (YYYY-MM-DD) |
| `expires_at` | 아니요 | 만료일. 지나면 검사가 실패한다 |
| `attribution` | 예 | 화면에 그대로 보여 줄 출처 표기 문구 |
| `excludes` | 아니요 | 이 라이선스로 쓸 수 없는 것. 예: VOA의 통신사(AP·로이터·AFP) 기사·사진 |

## Series (시리즈) — 2026-11-12, 있을 때만

콘텐츠 고르기 화면에서 묶는 단위. 과가 52개처럼 많아져도 한 화면에서 고르려고 만들었다.

| 칸 | 필수 | 뜻 |
|---|---|---|
| `id` | 예 | 영문 소문자·숫자 |
| `title`, `title_ko` | 예 | 영어·한국어 이름 |
| `kind` | 예 | `course`(번호 순서로 배우는 과정 → 번호 칸) / `collection`(순서 없는 모음 → 제목 목록) |

## Content (콘텐츠 한 편)

| 칸 | 필수 | 뜻 |
|---|---|---|
| `id` | 예 | 영문 소문자·숫자·하이픈, 겹치면 안 됨 |
| `title` | 예 | 영어 제목 |
| `title_ko` | 예 | 한국어 제목 |
| `level` | 예 | CEFR `A1`~`C2` |
| `topics` | 예 | 관심사 id 1~3개 (`work` `travel` `daily` `food` `health` `science` `culture` `sports` `news`) |
| `license_id` | 예 | `licenses`에 있는 id |
| `source_url` | 예 | 원문 페이지 |
| `audio` | 예 | `{ "src": "audio/파일.mp3", "duration_ms": 정수 }`. 파일은 `site/audio/`에 둔다 |
| `sentences` | 예 | 문장 목록 (아래) |
| `added_at` | 예 | 넣은 날 |
| `series`, `series_no` | 아니요 | 시리즈 id와 그 안의 번호(1부터, 겹치면 안 됨) |
| `reviewed` | 예 | 사람이 번역·시간 정보를 확인했으면 `true`. `false`면 화면에 내보내지 않는다 |

## Sentence (문장)

| 칸 | 필수 | 뜻 |
|---|---|---|
| `start_ms` | 예 | 원음에서 문장이 시작하는 시각 (밀리초) |
| `end_ms` | 예 | 끝나는 시각. `start_ms`보다 커야 한다 |
| `speaker` | 아니요 | 말하는 사람 이름 |
| `en` | 예 | 영어 원문 |
| `ko` | 예 | 한국어 번역 (사람 확인) |

사람이 귀로 듣고 시각을 고칠 때는 후보 파일 `<id>.ko.json`의 `timing_fix`에 `{"문장 번호": {"start_ms"|"end_ms": 값, "why": 이유}}`로 적는다. 장면 경계를 고정할 때는 `scenes`에 `[[첫, 끝], ...]`.

검사가 확인하는 것: 문장은 시각 순서대로 온다. 앞 문장과 0.15초 넘게 겹치면 실패한다(비기능 요구사항 '문장 경계 오차 0.15초 이내'를 허용 폭으로 쓴다). 마지막 문장은 음성 길이를 넘지 않는다.

## Scene (장면) — 2026-11-12

`scenes = [{ "from": 첫 문장 번호, "to": 끝 문장 번호 }]` (0부터, 끝 포함). 빈틈없이 전체를 덮는다. 수준별 최대 길이(A1·A2 30초, B1 60초, B2 이상 120초)를 넘지 않는다. `pipeline/scenes.py`가 만든다.

## Expression (표현 익히기) — 2026-11-12, 있을 때만

| 칸 | 뜻 |
|---|---|
| `scene`, `sentence` | 장면 번호, 그 장면 안의 문장 번호 (0부터) |
| `match` | 대본에서 표시할 글자 그대로 (예: `giving new assignments out`) |
| `text` | 표현의 기본형 (예: `give out`) |
| `type` | `phrasal_verb`(구동사) / `idiom`(관용 표현) / `chunk`(덩어리 표현) / `word`(단어) |
| `meaning_ko`, `note_ko` | 뜻, 쓰임 메모 |
| `similar` | 비슷한 표현 |
| `examples` | 바꿔 쓴 예문 1~3개 `{en, ko}` |

장면마다 최대 4개 (작업 기억이 한 번에 다루는 덩어리 약 4개: Cowan, 2001).

`glossary = { "단어": { "ko": 뜻, "cefr": 등급 } }`: 대본에서 누르면 나오는 단어 뜻. 교재 수준보다 높은 단어만.

## 저작권 메모

- 카드에는 학습자가 고른 짧은 문장만 남긴다 (기능요구서 '콘텐츠 정책').
- 사용자가 가져온 콘텐츠(F-04, 2차)는 이 파일에 넣지 않는다. 기기 안에만 둔다.
